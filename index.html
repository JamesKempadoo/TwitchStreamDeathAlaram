Setting up Environment Variables & GitHub Secrets

  1. Local Setup (.env):

    Edit .env in your repository root:

    TWITCH_CLIENT_ID=your_actual_client_id_here

    Run npm run build locally to generate config.js.

  2. GitHub Pages Secret Setup:

    Go to your GitHub Repository -> Settings -> Secrets and variables -> Actions.

    Click New repository secret:

    • Name: TWITCH_CLIENT_ID
    • Secret: Paste your Twitch Application Client ID
  3. Automatic GitHub Actions Deployment:

    Pushing to main automatically runs GitHub Actions, injects your secret into config.js, and deploys to GitHub Pages.
